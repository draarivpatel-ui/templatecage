# Changelog

## 1.0.0

Initial release.

- Multi-dialect iterative SSTI auditor for Mustache, Handlebars, Jinja, Twig, Liquid, Nunjucks, EJS, Pug, JavaScript interpolation, and Go template constructs
- Zero-eval safe Mustache subset compiler and renderer
- Own-property-only data lookup with getter, function, proxy, and prototype-chain isolation
- HTML, text, and JSON output modes
- Bounded nesting, loop depth, total iterations, input size, tag count, expression size, output size, and audit findings
- Frozen policy presets for strict, email, notification, and audit use
- Typed errors, TypeScript declarations, CLI, examples, dual ESM and CommonJS package output
